# Chikomos Portfolio

Full-stack portfolio app with Node.js/Express backend and Vanilla JS frontend.

## How to Run
1. Backend: cd Backend && npm install && node server.js (runs on port 10000)
2. Frontend: Open Frontend/index.html with Live Server
3. API: http://localhost:10000/api/portfolio

## Features
- View projects
- Add project
- Delete project
- Data saved in portfolio.json
